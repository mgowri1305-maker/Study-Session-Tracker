#  Study Session Tracker

A simple and user-friendly web application that helps students track their daily study sessions.

Users can add the subject, topic, and number of hours studied. The application automatically calculates the total study time and saves the sessions in the browser using localStorage.

## Features

-  Add study sessions
-  Enter subject and topic
-  Track study hours
-  Automatically calculate total study time
-  Delete study sessions
-  Save sessions using browser localStorage
-  Data remains available after refreshing the page
-  Basic input validation
-  Simple and responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
